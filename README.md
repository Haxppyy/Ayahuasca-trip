# ✦ AYAHUASCA — A JOURNEY BEYOND REALITY

### *What if you could visualize the impossible?*

An immersive, interactive 3D experience inspired by the surreal, dreamlike, and deeply mysterious dimensions of human consciousness.

Built with **Three.js**, this experiment transforms abstract feelings, psychedelic geometry, cosmic environments, and flowing particles into an interactive visual journey.

Not just a 3D scene.

A journey through the unknown.

## 🚀 RUN LOCALLY

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Navigate into the project:

```bash
cd ayahuasca-experience
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL provided by your development server.
